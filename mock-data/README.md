# mock-data

Test data for trying the headset flow before real search is wired in.

`sf_restaurants.json` holds 80 **fictional** San Francisco restaurants: made-up names and addresses (marked "(mock)"), with real neighbourhood names. Each one has the filters the EEG restaurant test asks about:

| Filter | Values |
|---|---|
| cuisine | Italian, Japanese, Mexican, Chinese, Thai, Indian, American, Vietnamese |
| neighborhood | Mission, North Beach, Chinatown, SoMa, Hayes Valley, Marina, Inner Richmond, Sunset |
| price | $ to $$$$ |
| diet | vegetarian friendly, vegan options, gluten free options, no special diets |
| vibe | casual, date night, family friendly, quick bite |

Each restaurant also has a rating, open late, outdoor seating, takes reservations, and a one-line description that Moss indexes.

The file is generated by `python generate_restaurants.py`, which uses a fixed seed, so it is the same every time. The test that uses it is `eeg-data/restaurant_demo.py`.
